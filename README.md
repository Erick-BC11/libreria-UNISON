# libreria-UNISON
Se diseñó una interfaz nueva para el inicio de sesión para acceder a la librería digital de la UNISON. El único requisito que se nos dió fue que cumpliera todos las funciones/diseños necesarios que necesitara cada proceso o cosa que sucediera cuando alguien intenta acceder, ya sea que pone una contraseña mal, alguna pantalla de carga, etc.
