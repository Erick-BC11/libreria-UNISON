# libreria-UNISON
Creadores: Brandon Isaac Miranda Montes, Juraz Gael Miranda Coronado y Erick Bustamamnte Cruz


Se diseñó una interfaz nueva para el inicio de sesión para acceder a la librería digital de la UNISON. El único requisito que se nos dió fue que cumpliera todos las funciones/diseños necesarios que necesitara cada proceso o cosa que sucediera cuando alguien intenta acceder, ya sea que pone una contraseña mal, alguna pantalla de carga, etc.


![Interfaz de inicio de sesión 1](1.jpg)
Pantalla principal de inicio de sesión con campos para el usuario o correo institucional, contraseña (con opción para hacerla visible) y un botón de "Aceptar".


![Interfaz de inicio de sesión 2](2.jpg)
Pantalla de bienvenida que aparece al iniciar sesión correctamente, saludando al estudiante por su nombre con un botón para ingresar al sistema.


![Interfaz de inicio de sesión 3](3.jpg)
Pantalla de error de credenciales, donde se notifica con texto y bordes rojos que el usuario o la contraseña ingresados son incorrectos.


![Interfaz de inicio de sesión 4](4.jpg)
Formulario de registro para nuevos usuarios, solicitando nombre, correo electrónico, contraseña y la confirmación de la misma.


![Interfaz de inicio de sesión 5](5.jpg)
Aviso de falta de conexión a internet, indicando que el dispositivo está sin red mediante un ícono de carga.


![Interfaz de inicio de sesión 6](6.jpg)
Mensaje de error interno que indica una caída en la conexión con el servidor, ilustrado con un corazón roto y un botón para aceptar el mensaje.

![Interfaz de inicio de sesión 7](7.jpg)
Variante alternativa de la pantalla de inicio de sesión que simplifica el primer campo solicitando únicamente el "Usuario" en lugar de dar la opción del correo institucional.
